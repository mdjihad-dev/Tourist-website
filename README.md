# Tourist Website

A responsive travel-focused landing page built with HTML and CSS. The project presents a simple tourism interface with destination-focused content and responsive styling.

## Tech Stack

- HTML5
- CSS3
- Responsive Web Design

## Highlights

- Travel-focused hero section
- Destination and content sections
- Responsive layout
- Custom image assets
- Clean semantic page structure

## Getting Started

```bash
git clone https://github.com/mdjihad-dev/Tourist-website.git
cd Tourist-website
```

Open `Index.html` in a browser to view the project.

## Project Focus

Built to practice responsive layouts, CSS styling, page structure, and visual presentation using plain HTML and CSS.
